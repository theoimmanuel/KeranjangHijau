# KeranjangHijau
KeranjangHijau merupakan platform yang memungkinkan pembeli online dan bisnis e-commerce mengimbangi jejak karbon dari pembelian, membuat pesanan menjadi netral karbon sambil mendorong konsumsi yang berkelanjutan.
